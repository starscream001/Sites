# График 446

Статический сайт в основной ветке main. Исходные данные: «ГРАФИК 446.ods»; последние четыре месяца листа «ГРАФИК» — сентябрь–декабрь 2026. Импортированы все десять сотрудников последнего блока 2026 года листа «отпуска», у четырёх есть ежедневный график за выбранный период.

По уточнению пользователя отметка «9» означает начало смены в 09:00. Рабочая смена длится 12 часов. Пустая ячейка в существующей строке означает выходной; «о» — отпуск. Отсутствующая строка означает отсутствие данных. Подсчёты выполняются по ежедневным ячейкам, а не по итоговым формулам файла.

Недельные отметки отпусков импортированы вместе с красной заливкой, даже если в ячейке нет текста. Метки «1» сохранены отдельно от заливки. В источнике нет точных дат для этих недель; они не превращаются в конкретные даты и не перезаписывают календарь. Архивные блоки справа за другие годы исключены.

Данные статичны. Для обновления: `python3 scripts/import_schedule.py '/путь/к/ГРАФИК 446.ods'`. Импортёр сохраняет SHA-256 исходного файла и номера строк для прослеживаемости. Файл ODS не меняется и не включается в публикацию.

Запуск: `npm run dev`. Проверки: `npm test`. Сборка: `npm run build`.

Локальный предварительный просмотр обслуживает только файлы сайта; приватные файлы проекта недоступны. Публикуется только содержимое dist. Папка .idea и существующие справочные файлы не менялись. Предыдущий локально изменённый index.html сохранён перед заменой в /private/tmp/sites-index-before-schedule.html.
